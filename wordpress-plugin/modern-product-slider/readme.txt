Beautiful, fast WooCommerce product sliders. Shortcode and Gutenberg block included.

== Description ==

Modern Product Slider shows your WooCommerce products in a clean, responsive slider.

* Add the shortcode `[modern_product_slider limit="8" columns="4"]` to any page, post or widget.
* Or add the "Product Slider" block in the block editor.
* Works with any theme. No setup needed.

Pro (from $3/month) unlocks unlimited sliders, unlimited products per rack and priority support. Connect your site under **Product Slider** in the WordPress admin with the license key from your dashboard.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/modern-product-slider/`, or install the ZIP via Plugins → Add New → Upload.
2. Activate the plugin.
3. Make sure WooCommerce is installed and active.
4. Add `[modern_product_slider]` to a page, or add the Product Slider block.

== Frequently Asked Questions ==

= Do I need WooCommerce? =
Yes — the slider shows your WooCommerce products. Without WooCommerce it shows a short notice instead.

= How do I connect my site to the dashboard? =
Buy a plan on the Modern Product Slider website, copy the license key from your dashboard (Licenses page), then go to **Product Slider** in WordPress, paste the key and click "Connect site & activate Pro".

= How do updates work? =
When a new version is published on the dashboard, WordPress shows the update under Dashboard → Updates for every site with an active license.
