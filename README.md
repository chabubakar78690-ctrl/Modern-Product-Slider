# Modern Product Slider — Official Pro Store & Admin Portal

Complete SaaS website for selling **Modern Product Slider Pro** licenses (`$3/mo` Single Site & `$10/mo` Unlimited Sites) with:
1. **Continue with Google** (supports real `VITE_GOOGLE_CLIENT_ID` OAuth or instant sandbox mode).
2. **Continue with Gmail Verification Code (6-Digit OTP)** — sends real emails via `RESEND_API_KEY` when configured on Vercel, and displays a live auto-fill test OTP badge when running without environment variables.
3. **Super Admin Dashboard (`/api/v1/admin/overview`)** — manage registered users, upgrade/downgrade plans, suspend/activate keys, release bound WordPress domains, export CSVs, view MRR & invoice reports, and monitor live WordPress API verification logs.
4. **WordPress License API (`/api/v1/license/verify` & `/deactivate`)** — connects directly to your WordPress Pro Add-On plugin.

## Admin Login
Sign in with `admin@modernproductslider.com` (either via the Gmail 6-digit code or Google sign-in) to unlock the **Admin Manager** button in the top navigation bar.
